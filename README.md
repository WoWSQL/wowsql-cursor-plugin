# WoWSQL for Cursor

WoWSQL is managed Postgres / BaaS. This plugin lets Cursor work with managed Postgres projects, tables, and SQL.

Hosted MCP server: `https://mcp.wowsql.com/mcp`

Cursor signs in with WoWSQL (WoWSQL OAuth).

Tools:

- `list_projects`
- `get_project`
- `list_tables`
- `execute_sql` (can write)
- `search_docs`
- `get_doc`

## Install

1. Install this plugin from the Cursor Marketplace, or clone this repo and add it as a local plugin.
2. Sign in with WoWSQL when Cursor prompts you.
