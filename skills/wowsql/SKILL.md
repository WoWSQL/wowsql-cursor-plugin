# WoWSQL

Use the WoWSQL MCP tools. The server is `https://mcp.wowsql.com/mcp`. Cursor signs in with WoWSQL OAuth.

- `list_projects`
- `get_project`
- `list_tables`
- `execute_sql` — can write
- `search_docs`
- `get_doc`
